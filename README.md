# Baumspiel – Fressmaul & Jet

Ein Browserspiel für zwei Kinder (ab ca. 6 Jahren) an einer Tastatur.

**Starten:** `index.html` im Browser öffnen (Doppelklick genügt, keine Installation nötig).

## Steuerung
| | Laufen / Fliegen |
|---|---|
| Spieler 1 (blau) | W A S D |
| Spieler 2 (rot)  | Pfeiltasten |

Leertaste = Start · Esc / P = Pause · M = Ton an/aus

## So geht's
1. Lauft durch den Wald. Geht ihr nah an einen **bösen Baum** (lila, stachelig), frisst ihn euer **Fressmaul** automatisch auf.
2. Die **lieben Bäume** (grün, lächelnd) werden nicht gefressen – sie kichern nur, wenn man sie besucht.
3. Böse Bäume werfen manchmal langsame Matschkugeln. Wer getroffen wird, ist kurz schwindelig – sonst passiert nichts.
4. Nach **5** bösen Bäumen verwandelt sich ein Fressmaul in einen **Jet**. Hinlaufen = einsteigen!
5. Der Jet fliegt über den Wald und schießt **automatisch Raketen** auf böse Bäume.
6. Nach **10** bösen Bäumen bekommt auch der andere Spieler seinen Jet.
7. Fliegt beide durch den **Regenbogen-Ring (ZIEL)** am Ende des Waldes – geschafft! Danach geht es ins nächste, etwas größere Level.
